# Currency Conventer

## Автор
Анастасия Рослякова

## Описание для конвертации  валют с использованием внешнего API и сохранением истории операций

## Требования
- Python 3.7 или выше
- Установленные зависимости requirements.txt

## Получение API-ключа
1. Зарегестрируйтесь на [exchange-api.com] (https://exchangerate-api.com.)
2. Получите бесплатный API-ключ.
3. В коде замените URL на версию с вашим ключом(если требуется).
